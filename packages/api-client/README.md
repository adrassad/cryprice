# @cryprice/api-client

**Public stub — planned TypeScript SDK**

This package is a placeholder in the public repository. It exports a minimal factory and is intended to grow into a typed HTTP client for the CryPrice REST API documented in [`docs/public-api.md`](../../docs/public-api.md).

It is **not production-ready** today. Use direct HTTP calls or copy patterns from [`examples/`](../../examples/) until the SDK is implemented.

```bash
npm install
npm run typecheck
```
