## What we can help with

- Questions about CryPrice read-only monitoring features
- Account access issues (Google OAuth for CryPrice account only)
- Public address monitoring configuration
- Documentation clarifications
- Responsible security reports

## What CryPrice does not do

CryPrice is not a wallet, exchange, custodian, or transaction service. We cannot:

- Connect to your wallet
- Recover seed phrases or private keys
- Execute blockchain transactions on your behalf
- Provide financial, investment, tax, or legal advice
