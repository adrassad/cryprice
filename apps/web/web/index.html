CryPrice — Read-Only DeFi Dashboard

CryPrice is a read-only DeFi risk intelligence dashboard for public address monitoring, portfolio visibility, and Aave Health Factor context across Ethereum, Arbitrum, Avalanche, and Base. This web application is the authenticated product surface for CryPrice — not a wallet, exchange, or transaction service.

What this application does

After account access is set up, you can add public blockchain addresses to monitor, review multi-address portfolio allocation, track Aave V3 supplied and borrowed positions, monitor Health Factor and liquidation proximity, export server-side PDF portfolio reports, and configure optional notification channels from your profile.

  • Multi-address portfolio dashboard across supported networks
  • Aave V3 Health Factor monitoring and protocol exposure views
  • Backend-calculated allocation by asset, debt, protocol, network, and public address
  • Read-only market and position data — no on-chain transaction execution

How account access works

How account access works — technical documentation for the Flutter Web sign-in flow and official CryPrice domains.

  1. Open this official app at app.cryprice.dev (linked from cryprice.dev).
  2. Use Google for CryPrice account access only — not wallet access.
  3. Add the public addresses you want to monitor.
  4. Review portfolio risk, Health Factor context, and optional alerts in the dashboard.

Read-only by design

Monitoring uses public on-chain and protocol data for addresses you choose to track. See the security model on cryprice.dev for data handling and scope.

Security Model

CryPrice is designed as a read-only platform.

The platform does not require users to provide:

  • recovery phrases (seed phrases);
  • private keys;
  • wallet signing credentials.

CryPrice does not execute blockchain transactions and does not take custody of user assets.

Authentication through Google OAuth is used only for CryPrice accounts and is unrelated to blockchain wallet authentication.

CryPrice does not require users to connect a wallet in order to monitor public blockchain addresses. Full trust documentation: Trust · Transparency · security.txt (security contact: security@cryprice.dev).
