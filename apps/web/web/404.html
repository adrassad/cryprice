About CryPrice

CryPrice is a read-only DeFi risk intelligence dashboard for public address monitoring, portfolio visibility, and Aave Health Factor context across Ethereum, Arbitrum, Avalanche, and Base. After account access is set up, you can add public addresses to monitor, review portfolio allocation, track Aave V3 supplied and borrowed positions, export server-side PDF portfolio reports, and configure optional notification channels from your profile.

This domain is the authenticated product surface. It is not a wallet, exchange, or on-chain transaction service. Trust and legal documentation is published on cryprice.dev.
